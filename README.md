# ⚡ שרת Wake-on-LAN עם בוט טלגרם וממשק ניהול (Docker)

שרת מבוסס Docker המאפשר להעיר מחשב מרחוק באמצעות **בוט טלגרם** או דרך **ממשק אינטרנט מעוצב (Web UI)** בפורט **`7892`**, עם ניטור בזמן אמת וקבלת התראה לטלגרם ברגע שהמחשב נדלק והתחבר לרשת.

---

## 🌟 יכולות המערכת

1. **ממשק ניהול דפדפן (Web UI) בפורט `7892`**:
   - ממשק מעוצב ומודרני בעברית מלאה (RTL) ותמיכה במצב כהה (Dark Mode).
   - הגדרה קלה של כל הפרמטרים: טוקן טלגרם, Chat ID מורשה, כתובת MAC, כתובת IP לניטור ועוד.
   - בדיקת חיבור מיידית לטלגרם (כולל שליחת הודעת בדיקה).
   - כפתורי פעולה מהירים: **"הער מחשב עכשיו"** ו-**"בדיקת פינג (Ping)"**.
   - יומן אירועים חי (Live Logs) המתעדכן בזמן אמת.

2. **בוט טלגרם חכם ומאובטח**:
   - מאזין לפקודות וכפתורים: `/wake`, `/status`, `/help`.
   - מנגנון הרשאות לפי **Chat ID / User ID** (רק משתמשים מורשים יכולים להעיר את המחשב).
   - מציג למשתמש חדש את ה-Chat ID שלו אוטומטית בהודעת `/start` לנוחות מרבית.

3. **שליחת אות התעוררות (Wake-on-LAN Magic Packet)**:
   - בנייה תקינה של פקט UDP Magic Packet (102 בייטים) ושליחה לכתובת Broadcast.

4. **מעקב וזיהוי הדלקה מהירה (Wake Detection)**:
   - ברגע שנשלחת פקודת התעוררות, השרת מתחיל לבדוק את זמינות המחשב ברשת (Ping / TCP).
   - **ברגע שהמחשב נדלק ומגיב ברשת**, נשלחת למשתמש בטלגרם הודעה מיידית:
     > *"🎉 המחשב נדלק והתחבר לרשת בהצלחה! 🟢 (זמן התעוררות: 14 שניות)"*

## 🚀 הפעלה מהירה באמצעות Docker

### 1. הפעלת הקונטיינר

בתיקיית הפרויקט, הרץ את הפקודה:

```bash
docker compose up -d --build
```

### 2. כניסה לממשק הניהול

פתח את הדפדפן בכתובת:
```
http://localhost:7892
```
*(או בכתובת ה-IP של השרת ברשת המקומית, למשל: `http://192.168.1.150:7892`)*

## 📋 שלבי ההגדרה בממשק

1. **פתיחת בוט בטלגרם**:
   - פתח את אפליקציית טלגרם וחפש את [**@BotFather**](https://t.me/BotFather).
   - שלח את הפקודה `/newbot`, עקוב אחר ההוראות ובחר שם וכינוי לבוט.
   - בסיום תקבל מחרוזת **API Token** (למשל: `123456789:ABCdefGhIJKlmNoPQRstuvwxYZ`).
   - הדבק את הטוקן בממשק הניהול בשדה **Telegram Bot Token**.

2. **מציאת ה-Chat ID שלך**:
   - לאחר שמירת הטוקן, חפש את הבוט שלך בטלגרם ושלח לו `/start`.
   - הבוט ישיב לך עם ה-Chat ID שלך (מספר מזהה ייחודי).
   - העתק את המספר והזן אותו בשדה **Allowed Chat ID / User ID** בממשק ולחץ שמירה.

3. **הגדרת מחשב היעד (MAC ו-IP)**:
   - **כתובת MAC**: הזן את ה-MAC של כרטיס הרשת (למשל: `AA:BB:CC:DD:EE:FF`). במחשב היעד תוכל לגלות זאת בהרצת `ipconfig /all` או `getmac`.
   - **כתובת IP**: הזן את כתובת ה-IP של המחשב (מומלץ לקבוע IP סטטי בראוטר) כדי שהשרת יוכל לבצע Ping ולזהות כשהמחשב נדלק.
   - לחץ על **"שמור הגדרות והפעל מחדש בוט"**.

## 💡 הגדרות נדרשות במחשב היעד להפעלת Wake-on-LAN

כדי שמחשב יוכל להתעורר מפקט רשת, יש לוודא שהתכונה מופעלת:

1. **בהגדרות ה-BIOS/UEFI**:
   - היכנס ל-BIOS בעליית המחשב (מקש `Del` או `F2`).
   - חפש הגדרות בשם: **Wake on LAN**, **Power On By PCI-E Device**, או **Network Boot**.
   - ודא שהאפשרות מוגדרת על **Enabled**.

2. **ב-Windows (במנהל ההתקנים)**:
   - לחץ מקש ימני על התחל &larr; **Device Manager (מנהל ההתקנים)**.
   - הרחב את **Network adapters (מתאמי רשת)** ובחר את כרטיס הרשת הקווי (Ethernet).
   - לחץ מקש ימני &larr; **Properties (מאפיינים)**:
     - בלשונית **Power Management (ניהול צריכת חשמל)**: סמן ב-V את:
       - *Allow this device to wake the computer*
       - *Only allow a magic packet to wake the computer*
     - בלשונית **Advanced (מתקדם)**: ודא ש-**Wake on Magic Packet** מוגדר כ-**Enabled**.
3. **חיבור כבל רשת**:
   - Wake-on-LAN סטנדרטי עובד על חיבור רשת קווי (Ethernet).

## 🌐 הערה לגבי רשת ב-Docker (Linux vs Windows)

- **בשרת לינוקס / HomeLab / Raspberry Pi / Unraid / Synology**:
  על מנת שחבילות UDP Broadcast יגיעו ישירות למתאם הרשת הפיזי, מומלץ לפתוח את `docker-compose.yml` ולהפעיל את השורה `network_mode: host` (ולסמן בסולמית את `ports:`).
- **ב-Windows Docker Desktop**:
  ברירת המחדל מוגדרת עם מיפוי פורט `7892:7892`, והשרת תומך גם בשידור Broadcast ישיר לתת-הרשת (למשל `192.168.1.255`).

## 🛠️ פקודות בוט הטלגרם

| פקודה | תיאור |
|---|---|
| `/start` | הודעת פתיחה וכפתורים מהירים |
| `/wake` | שולח אות Wake-on-LAN ומתחיל ניטור עד שהמחשב נדלק |
| `/status` | בודק האם המחשב דולק כעת (Ping) ומחזיר סטטוס |
| `/help` | רשימת הפקודות והסברים |
